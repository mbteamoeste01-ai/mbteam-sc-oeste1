# MB Team SC Oeste1 — site informativo
Site estático responsivo para GitHub Pages com foco em explicar a academia e levar o visitante a agendar aula experimental pelo WhatsApp.

## Incluído
- Apresentação da academia e informações sobre Muay Thai para adultos e crianças.
- Carrossel automático com quatro espaços para fotos, troca a cada 5 segundos, setas e indicadores.
- Grade de horários fornecida pela academia.
- Seção de localização com botão para abrir o Google Maps.
- Identidade visual baseada na logo oficial: preto, dourado, verde e detalhes vermelhos.

## Fotos do carrossel
Coloque quatro fotos reais na pasta `fotos` e nomeie `foto-1.jpg`, `foto-2.jpg`, `foto-3.jpg`, `foto-4.jpg`. Recomendado: imagens horizontais de boa qualidade, preferencialmente próprias e com autorização das pessoas fotografadas.

## Configurar WhatsApp
Edite `config.js` e preencha `whatsappNumber` com o número oficial, incluindo DDI + DDD + número, somente dígitos (formato `55DD9XXXXXXXX`). Teste o botão antes de divulgar. Não invente ou use número provisório.

## Publicar
1. Crie um repositório público `mbteam-sc-oeste1` no GitHub.
2. Envie os arquivos da pasta, incluindo a pasta `fotos`.
3. Em **Settings → Pages**, selecione **Deploy from a branch**, branch `main`, pasta `/(root)` e salve.
4. URL esperado: `https://SEU-USUARIO.github.io/mbteam-sc-oeste1/`.

## Observações
- A localização usa um cartão ilustrativo e um link direto para o Google Maps fornecido. Para um mapa real incorporado dentro da página, será preciso obter o endereço público ou o código de incorporação do Google Maps.
- O WhatsApp está intencionalmente sem configurar até que seja fornecido o número oficial.
- Esta versão é informativa; não coleta matrículas nem envia e-mails.
- Horários exibidos conforme a grade enviada. Confirme disponibilidade antes do agendamento.
